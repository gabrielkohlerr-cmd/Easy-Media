# Easy Media

Protótipo funcional da Easy Media: gestão de conteúdo para redes sociais com
fluxo de aprovação de cliente e relatórios de desempenho.

Duas visões:

- **Visão Social Media** — fila de conteúdo, alterações solicitadas pelo
  cliente e insights de desempenho.
- **Visão Cliente** — aprovação (ou solicitação de alteração) dos posts
  pendentes e métricas de posts já publicados.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
